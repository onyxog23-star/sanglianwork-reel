# Sanglianwork ASCII Reel

A 3D "S" monogram drawn entirely out of text characters, with the Python code that makes it typing out underneath. It renders a ready-to-post Instagram Reel (1080×1920, 30 fps, 20 s).

Made by **Sangliana** · [sanglianwork.de](https://sanglianwork.de)

## Make your own (no install)
1. Click **Fork** (top right) to copy this repo to your account
2. Go to **Actions** → **Make reel** → **Run workflow**
3. Type your own letter (e.g. `A` or `JK`) and labels → **Run workflow**
4. Wait ~3 minutes → open the run → download your video under **Artifacts**
